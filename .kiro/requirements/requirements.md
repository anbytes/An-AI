# AI 聊天机器人网页 - 需求文档

## 1. 项目概述

### 1.1 项目名称

An-AI - 智能聊天机器人网页应用

### 1.2 项目描述

一个支持多个免费 AI 模型切换的聊天机器人网页应用，提供类似 ChatGPT 的用户体验。用户可以通过昵称区分身份，管理多个对话会话，享受流式输出、Markdown 渲染、代码高亮等功能。

### 1.3 目标用户

- 个人开发者
- AI 爱好者
- 需要免费 AI 对话工具的用户

### 1.4 技术栈

| 层级        | 技术选型                                 |
| ----------- | ---------------------------------------- |
| 前端        | Vue 3 + TypeScript + Element Plus + Vite |
| 后端        | Node.js + Express + TypeScript           |
| 数据库      | SQLite                                   |
| 状态管理    | Pinia                                    |
| HTTP 客户端 | Axios                                    |

## 2. 功能需求

### 2.1 用户模块

#### 2.1.1 用户识别

- **需求描述**：支持多用户但无需注册，通过昵称区分用户
- **功能点**：
    - 首次访问时提示输入昵称
    - 昵称存储在本地（localStorage）和数据库
    - 支持修改昵称
    - 不同昵称的用户数据相互隔离

#### 2.1.2 用户偏好设置

- **需求描述**：用户可以自定义个人偏好
- **功能点**：
    - 默认 AI 模型选择
    - 界面语言设置（预留）
    - 其他个性化配置

### 2.2 AI 模型模块

#### 2.2.1 多模型支持

- **需求描述**：支持多个免费 AI 模型切换
- **支持的模型**：

| 分类 | 服务商   | 模型                                   | 免费额度           | 说明             |
| ---- | -------- | -------------------------------------- | ------------------ | ---------------- |
| 国内 | 通义千问 | qwen-turbo、qwen-plus                  | 免费额度           | 阿里云，国内首选 |
| 国外 | Groq     | llama-3.1-70b、mixtral-8x7b、gemma2-9b | 免费（有速率限制） | 速度极快         |

- **功能点**：
    - 在设置面板中切换模型
    - 显示当前使用的模型名称
    - 模型配置（API Key、API 地址、模型参数）
    - 模型可用性检测
    - 支持自定义添加兼容 OpenAI 格式的 API

#### 2.2.2 模型参数配置

- **需求描述**：支持调整模型参数
- **可配置参数**：
    - Temperature（创造性程度）
    - Max Tokens（最大输出长度）
    - Top P（采样参数）
    - 系统提示词（System Prompt）

### 2.3 对话模块

#### 2.3.1 基础对话功能

- **需求描述**：实现基础的文字对话功能
- **功能点**：
    - 用户输入消息并发送
    - AI 返回响应消息
    - 消息显示时间戳
    - 区分用户消息和 AI 消息的样式

#### 2.3.2 流式输出

- **需求描述**：实现打字机效果的流式输出
- **功能点**：
    - 使用 Server-Sent Events (SSE) 或 WebSocket
    - 逐字/逐词显示 AI 响应
    - 显示"正在输入..."状态
    - 支持中断生成

#### 2.3.3 多轮对话上下文

- **需求描述**：支持多轮对话的上下文管理
- **功能点**：
    - 自动携带历史消息作为上下文
    - 可配置上下文长度（最近 N 条消息）
    - 上下文 Token 计数显示（可选）

#### 2.3.4 消息编辑和重新生成

- **需求描述**：支持编辑已发送的消息并重新生成回复
- **功能点**：
    - 编辑用户消息
    - 重新生成 AI 回复
    - 保留或删除原有回复

### 2.4 会话管理模块

#### 2.4.1 会话列表

- **需求描述**：支持管理多个对话会话
- **功能点**：
    - 创建新会话
    - 删除会话
    - 重命名会话
    - 切换会话
    - 会话列表按时间排序

#### 2.4.2 会话存储

- **需求描述**：会话数据持久化存储
- **功能点**：
    - 会话标题自动生成（基于首条消息）
    - 会话创建时间、更新时间记录
    - 每个会话保留最近 20 条聊天记录

### 2.5 消息渲染模块

#### 2.5.1 Markdown 渲染

- **需求描述**：支持 Markdown 格式的消息渲染
- **支持的格式**：
    - 标题（H1-H6）
    - 粗体、斜体、删除线
    - 有序/无序列表
    - 引用块
    - 链接、图片
    - 表格
    - 分割线

#### 2.5.2 代码高亮

- **需求描述**：支持代码块的语法高亮显示
- **功能点**：
    - 自动识别编程语言
    - 语法高亮显示
    - 代码块复制按钮
    - 行号显示（可选）

### 2.6 导出模块

#### 2.6.1 对话导出

- **需求描述**：支持将对话导出为文件
- **支持的格式**：
    - Markdown (.md)
    - 纯文本 (.txt)
    - PDF（可选，后续实现）
- **功能点**：
    - 导出当前会话
    - 选择导出格式
    - 自定义文件名

### 2.7 设置模块

#### 2.7.1 设置面板

- **需求描述**：提供统一的设置入口
- **设置项**：
    - AI 模型选择和配置
    - API Key 管理
    - 模型参数调整
    - 用户昵称修改
    - 上下文长度设置
    - 清除所有数据

## 3. 界面需求

### 3.1 整体布局

- **布局方式**：左右分栏布局
    - 左侧：会话列表侧边栏（可折叠）
    - 右侧：聊天主界面
- **风格**：简洁现代风格，类似 ChatGPT

### 3.2 侧边栏

- **功能**：
    - 新建会话按钮
    - 会话列表（显示标题和时间）
    - 会话操作（重命名、删除）
    - 设置入口
    - 折叠/展开按钮

### 3.3 聊天主界面

- **组成部分**：
    - 顶部：当前会话标题 + 模型名称
    - 中部：消息列表区域（可滚动）
    - 底部：输入框 + 发送按钮

### 3.4 消息气泡

- **用户消息**：右对齐，深色背景
- **AI 消息**：左对齐，浅色背景，支持 Markdown 渲染
- **消息元素**：头像、昵称/模型名、时间戳、操作按钮

### 3.5 设置面板

- **展示方式**：抽屉（Drawer）或对话框（Dialog）
- **分组**：模型设置、用户设置、高级设置

## 4. 数据库设计

### 4.1 用户表 (users)

| 字段名     | 类型        | 说明       |
| ---------- | ----------- | ---------- |
| id         | INTEGER     | 主键，自增 |
| nickname   | VARCHAR(50) | 用户昵称   |
| created_at | DATETIME    | 创建时间   |
| updated_at | DATETIME    | 更新时间   |

### 4.2 会话表 (conversations)

| 字段名     | 类型         | 说明          |
| ---------- | ------------ | ------------- |
| id         | INTEGER      | 主键，自增    |
| user_id    | INTEGER      | 用户 ID，外键 |
| title      | VARCHAR(100) | 会话标题      |
| model      | VARCHAR(50)  | 使用的模型    |
| created_at | DATETIME     | 创建时间      |
| updated_at | DATETIME     | 更新时间      |

### 4.3 消息表 (messages)

| 字段名          | 类型        | 说明                          |
| --------------- | ----------- | ----------------------------- |
| id              | INTEGER     | 主键，自增                    |

| role            | VARCHAR(20) | 角色（user/assistant/system） |

| created_at      | DATETIME    | 创建时间                      |

### 4.4 系统配置表 (settings)

| 字段名     | 类型        | 说明                |
| ---------- | ----------- | ------------------- |
| id         | INTEGER     | 主键，自增          |
| user_id    | INTEGER     | 用户 ID，外键       |
| key        | VARCHAR(50) | 配置键              |
| value      | TEXT        | 配置值（JSON 格式） |

## 5. API 接口设计

### 5.1 用户接口

| 方法 | 路径           | 说明                      |
| ---- | -------------- | ------------------------- |
| POST | /api/users     | 创建/获取用户（通过昵称） |
| PUT  | /api/users/:id | 更新用户昵称              |

### 5.2 会话接口

| 方法   | 路径                   | 说明               |
| ------ | ---------------------- | ------------------ |
| GET    | /api/conversations     | 获取用户的会话列表 |
| POST   | /api/conversations     | 创建新会话         |
| PUT    | /api/conversations/:id | 更新会话（重命名） |
| DELETE | /api/conversations/:id | 删除会话           |

### 5.3 消息接口

| 方法   | 路径                            | 说明                   |
| ------ | ------------------------------- | ---------------------- |
| GET    | /api/conversations/:id/messages | 获取会话的消息列表     |
| POST   | /api/conversations/:id/messages | 发送消息并获取 AI 回复 |
| PUT    | /api/messages/:id               | 编辑消息               |
| DELETE | /api/messages/:id               | 删除消息               |

### 5.4 AI 对话接口

| 方法 | 路径                 | 说明                     |
| ---- | -------------------- | ------------------------ |
| POST | /api/chat            | 发送对话请求（流式响应） |
| POST | /api/chat/regenerate | 重新生成回复             |

### 5.5 设置接口

| 方法 | 路径          | 说明         |
| ---- | ------------- | ------------ |
| GET  | /api/settings | 获取用户设置 |
| PUT  | /api/settings | 更新用户设置 |

### 5.6 导出接口

| 方法 | 路径                        | 说明                         |
| ---- | --------------------------- | ---------------------------- |
| GET  | /api/export/:conversationId | 导出会话（支持 md/txt 格式） |

## 6. 非功能需求

### 6.1 性能需求

- **并发用户**：个人使用，单用户
- **响应时间**：流式输出，首字节响应 < 2 秒
- **数据存储**：每个会话保留最近 20 条消息

### 6.2 安全需求

- **API Key 管理**：通过环境变量配置，不提交到 Git
- **请求频率限制**：防止滥用，限制每分钟请求次数
- **输入验证**：防止 XSS 和注入攻击

### 6.3 可维护性需求

- **代码注释**：全部使用中文注释，详细注释每个函数和复杂逻辑
- **文档**：提供详细的安装、配置、使用文档
- **代码结构**：按文件类型分组（components/views/utils/api）

### 6.4 部署需求

- **本地运行**：支持一键启动前后端
- **代码托管**：GitHub 仓库
- **环境配置**：提供 .env.example 示例文件
