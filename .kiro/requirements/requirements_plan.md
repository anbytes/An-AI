# AI 聊天机器人网页 - 需求计划

## 项目概述

创建一个 AI 聊天机器人网页应用，使用 Vue 3 + TypeScript + Element Plus 作为前端，Node.js 作为后端，SQLite 作为数据库。项目需要支持本地部署和 GitHub 运行。

## 需求汇总

根据你的回答，项目需求汇总如下：

### 核心需求

1. **AI 模型**：支持多个免费模型切换（国内外免费 API + 本地模型）
2. **用户系统**：支持多用户但无需注册（通过昵称区分）
3. **会话管理**：支持创建、删除、重命名、切换多个对话
4. **核心功能**：
    - ✅ 基础文字对话
    - ✅ Markdown 渲染
    - ✅ 代码高亮显示
    - ✅ 流式输出（打字机效果）
    - ✅ 对话导出（PDF、TXT、Markdown）
    - ✅ 多轮对话上下文管理
    - ✅ 消息编辑和重新生成
    - ⏸️ 文件上传（待开发）
    - ⏸️ 语音输入/输出（待开发）
    - ⏸️ 收藏/标记重要消息（待开发）

### 技术架构

- **前端**：Vue 3 + TypeScript + Element Plus + Vite
- **后端**：Node.js + Express/Koa + TypeScript
- **数据库**：SQLite（存储用户信息、聊天记录、会话列表、系统配置、用户偏好）
- **部署**：代码托管在 GitHub，支持本地运行

### 非功能性需求

- **性能**：个人使用，实时流式输出，保留最近 20 条聊天记录
- **安全**：环境变量配置 API Key，请求频率限制，本地开发无需 HTTPS
- **可维护性**：详细的开发文档和中文注释
- **UI/UX**：简洁现代风格（类似 ChatGPT），侧边栏会话列表 + 设置面板
- **开发策略**：先实现 MVP，后续迭代添加功能
