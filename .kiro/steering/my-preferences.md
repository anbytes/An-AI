# 我的开发习惯和要求

## 编码风格

- **缩进**：2 个空格
- **分号**：使用分号
- **引号**：单引号
- **行尾逗号**：不使用
- **每行最大字符数**：100
- **箭头函数括号**：单参数时省略括号
- **格式化工具**：Prettier + ESLint

## 技术栈

### 前端

- **主要技术栈**：Vue 3 全家桶（Vue 3 + Vue Router + Pinia/Vuex + TypeScript）
- **UI 框架**：Element UI
- **其他熟悉的技术**：
    - Vue 2
    - React
    - 原生 JavaScript/HTML/CSS
    - TypeScript

### 后端

- **主要技术栈**：Node.js
- **其他**：略懂 Python

### 数据库

- 完全不懂数据库

## 代码注释

- **注释语言**：全部使用中文注释
- **注释详细程度**：详细注释，每个函数、复杂逻辑都要添加注释

## 项目结构

- **文件组织方式**：按文件类型分组（components/views/utils/api）
- **组件文件命名**：使用 PascalCase（例如：UserProfile.vue）
- **路径别名**：使用 @ 指向 src 目录

## 测试要求

- **测试策略**：只在复杂功能时编写测试
- **测试框架**：无特定要求

## 文档规范

- **文档语言**：中文
- **文档详细程度**：详细文档，包含安装、配置、使用示例、API 文档等
- **代码示例**：需要提供详细的代码示例

## 其他规范

暂无
